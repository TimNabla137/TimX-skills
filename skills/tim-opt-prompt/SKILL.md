# Tim Opt Prompt

把用户的原始要求改写成专业、具体、可验证的提示词。核心原则：**把任务做得更深入，而不是把任务范围扩大。**

## 使用方式

将用户本次提供的要求或明确指向的上下文作为原始提示词；只调用本 Skill 而没有可识别的待优化内容时，请用户提供原始要求。保留原有目标、对象、范围、交付物及时间、预算、技术和授权约束。

先回答下面四个问题，再根据答案重写提示词。四问由你回答，不是转交给用户的问卷。已有信息足够时直接完成；只有缺失信息会实质改变目标、范围或正确性时才提出必要澄清，其他未知项使用明确的假设或占位符。

## 先回答四个问题

### 1. 这个领域最顶尖的专业人士，会做哪些我目前没有要求你做的事情？

识别影响原目标成败的关键遗漏，例如定义判定标准、追查根因、核对边界条件、检验反例或审查关键假设。说明各项为什么必要。只纳入深化现有任务的方法；新的业务目标、功能或交付物应留在范围之外，不因“专家会做”就自动加入。

### 2. 相比那些已经整理、加工过的信息，他们会从哪些最原始的材料入手？

指出适合该任务的一手材料及其用途，例如原始数据、实际代码和日志、合同原件、法规原文、访谈逐字稿、实验记录或直接观察。优先选择能追溯来源、时间、版本和上下文的材料，区分当前已提供的材料与后续需要取得的材料，不把摘要、转述或模型生成内容冒充一手证据。

### 3. 他们会使用哪些具体的方法和工具？

把方法写成可执行操作，说明使用什么输入、如何处理、产出什么，以及为何适合此任务。工具需服务于方法，优先复用现有能力；不堆砌工具名，不默认购买、安装或取得尚未获得的访问权限。尚未确认可用的工具明确标为候选，并在需要时给出可行替代。

### 4. 除了你和我自己的判断，还有什么外部证据能够证明结果是正确的？

为关键结论或交付物匹配可观察的验收证据，例如独立数据、可复现实验、测试结果、权威原文、第三方复核或真实用户行为。说明证据如何取得、什么结果算通过，以及什么结果会推翻结论。多个转述同一来源的信息不算独立验证；无法严格证明的判断，应说明证据能支持到什么程度和剩余不确定性。

## 再重写提示词

在四问之后，给出一份可直接复制、独立使用的完整提示词。使用与原始要求一致的语言，默认中文。

将四问中必要的内容落实为明确指令，覆盖原始目标与范围、优先检查的材料、具体操作方法、交付物及验收标准。每项新增要求都应能对应原目标的质量缺口；没有必要的条目不加入。不只写“请更专业”“深入分析”或“确保准确”。

重写后的提示词应要求执行者区分事实、推断、假设和未知项，报告证据出处、验证结果及限制。缺少真实依据时，要求说明待验证项，不能编造引用、数据、工具执行或验收结果。输出格式与任务复杂度相称，不机械要求每个任务都生成长报告。

默认交付到“四问答案 + 优化后的提示词”为止；只有用户同时授权执行时才继续执行重写后的任务。描述如何取得证据，不等于声称已经取得证据；本 Skill 本身不要求为每次改写开展完整调研。

## 输出顺序

1. **四问回答**：按上述四个问题依次回答，内容具体到当前任务，简洁说明理由。
2. **优化后的提示词**：用一个完整文本代码块提供可复制版本，写入必要背景，避免依赖“如上所述”。

交付前检查：四问是否确已回答；重写是否落实答案；是否保持原范围和约束；验收证据是否可检查；是否把未执行或无法确认的内容写成了事实。
