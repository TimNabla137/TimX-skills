# TimX skills

用于任务评估与日常排程的 Codex Skills。

## tim-daily-planning

结合 Eisenhower Matrix、Time Blocking 和番茄工作法：评估重要性与紧急性、预估耗时、集中处理琐事、安排深度和周期性工作，并在明确授权后将任务关联到日历。

入口：[`skills/tim-daily-planning/SKILL.md`](skills/tim-daily-planning/SKILL.md)。调用：`$tim-daily-planning`。

用户信息、工作时间、时区、资源标识和授权由所在项目或当前会话提供，仓库不包含个人配置或任务数据。安装不构成日历写入授权。
